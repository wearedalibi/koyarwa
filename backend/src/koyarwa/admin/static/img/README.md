# Images de l'administration

## `login.jpg` — fond de la page de connexion

Déposez ici l'image de fond du panneau gauche de la page de login :

- **Fichier attendu** : `login.jpg` (pour un autre format, adapter le chemin dans
  `admin/templates/login.html`).
- **Format conseillé** : haute résolution, ~1200×1600 px (portrait) ou paysage ;
  le sujet gagne à être un peu décalé vers la gauche (la droite est couverte par
  le panneau du formulaire sur les grands écrans).

Sans image, un **dégradé aux couleurs de la marque** s'affiche automatiquement (repli) —
la page reste donc présentable même avant d'ajouter la photo.
